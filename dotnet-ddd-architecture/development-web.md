## Agent 執行規則

1. 讀取本檔案後，已填寫的項目視為已確認，不再重複詢問
2. 空白或未填寫的項目，依 SKILL 的 Agent Flow 主動向使用者確認
3. 所有技術決策仍需產出「架構決策摘要」讓使用者最終確認
4. 確認完成後才進入骨架產出與功能開發
5. 開發過程中若發現本檔案的定義與實際需求衝突，優先以使用者最新指示為準
